Request Line — the auth-failure surface

Three options for #1011, against today’s sheet. All four are the same component (RequestLineFailureLabel inside RequestLineSheet); only the copy and the row’s contents differ. Sheet heights are the real presentationDetents values — the detent is fixed, so anything added to the failure row has to be budgeted for or it pushes “Dial a DJ” past the bottom edge.
